⚖ How They Differ
Aspect Option A · Floating Sheet Option B · Bottom Sheet
Position Drops down near the top, just below header Slides up from the bottom of the screen
Reachability Input is far from thumb on tall phones ✓ Thumb-friendly — input is near bottom
Feels like Quick popover / overlay Native iOS/Android sheet (Robinhood-style)
Keyboard interaction Keyboard pushes content down, may overlap ✓ Sheet hugs above keyboard naturally
Result list height Up to ~55vh (capped) Up to ~75vh, expandable
Dismiss gesture Tap × or outside Drag handle down, tap outside, or ×
My recommendation
Option B (Bottom Sheet) — feels native, more thumb-friendly, and the keyboard plays nicely with it (input stays right above the keyboard). It also gives more vertical room for search results without feeling cramped.
No matter which option you pick, the desktop / tablet (≥1024px) layout stays the same as today.
The FAB only appears on mobile/tablet (<1024px).
